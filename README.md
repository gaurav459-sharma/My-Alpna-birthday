# Birthday page

This project is a simple static website for a birthday surprise page.

## GitHub Pages

The site is ready to be published with GitHub Pages.

1. Create a new GitHub repository.
2. Push the contents of this folder to the repository.
3. In the repository settings, enable GitHub Pages and select the GitHub Actions deployment source.
4. After the workflow completes, your site will be available at:
   `https://<your-username>.github.io/<your-repo>/`
